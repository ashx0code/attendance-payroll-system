# 근태 관리 및 급여 자동 산출 시스템

정직원과 아르바이트가 함께 일하는 사업장을 위한 근태·급여 관리 서비스입니다.
**출퇴근 기록만으로** 주휴수당, 연장·야간·휴일 가산수당, 4대 보험과 원천징수까지 자동으로 계산하고,
모든 금액에 **산출 근거**를 함께 보여 줘서 급여를 둘러싼 오해와 분쟁을 줄이는 것을 목표로 합니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| Backend | Java 21, Spring Boot 4, Spring Security, Spring Data JPA |
| Frontend | SvelteKit, TypeScript |
| Database | PostgreSQL (운영), H2 (로컬) |
| Infra | Docker Compose, GitHub Actions |

## 프로젝트 구조

```
backend/    Spring Boot API 서버
frontend/   SvelteKit 웹 클라이언트
```

## 급여 계산 규칙

급여 계산 엔진(`backend/.../payroll/domain`)은 DB·웹 계층과 분리된 순수 도메인 로직이며,
규칙마다 단위 테스트로 검증합니다.

| 항목 | 규칙 |
|---|---|
| 기본급 | 시급제: 1일 8시간·1주 40시간 이내 근로시간 × 시급 / 월급제: 월 기본급 |
| 주휴수당 | 1주 소정근로시간 15시간 이상 + 소정근로일 개근 시 (소정근로시간 ÷ 40) × 8시간분, 최대 8시간 |
| 연장근로수당 | 1일 8시간 또는 1주 40시간 초과분 × 1.5 |
| 야간근로수당 | 22:00 ~ 06:00 근로분 × 0.5 가산 (휴게시간 제외) |
| 휴일근로수당 | 8시간 이내 × 1.5, 8시간 초과 × 2.0 |
| 5인 미만 사업장 | 연장·야간·휴일 가산 미적용 (주휴수당은 적용) |
| 월급제 통상시급 | 월 기본급 ÷ 월 소정근로시간(209시간) |
| 4대 보험 | 2026년 근로자 부담 요율, 10원 미만 절사 |
| 원천징수 3.3% | 소득세 3% + 지방소득세(소득세의 10%), 소득세 1,000원 미만 소액부징수 |

### 설계상 결정

- **자정을 넘긴 근무**는 출근일의 근무로 집계합니다.
- **주 단위 항목**(주휴수당, 주 40시간 초과 연장)은 그 주의 일요일이 속한 달에 정산합니다.
  월을 걸친 주도 이중 계산이나 누락 없이 한 번만 정산됩니다.
- 금액은 `BigDecimal`로 계산하고 원 단위 미만은 절사합니다.

## API

| Method | Path | 설명 |
|---|---|---|
| GET / PUT | `/api/workplace` | 사업장 정보, 5인 미만 사업장 여부 |
| POST | `/api/employees` | 직원 등록 (근로 조건 포함) |
| GET | `/api/employees?includeInactive=false` | 직원 목록 |
| GET / PUT | `/api/employees/{id}` | 직원 조회·수정 |
| DELETE | `/api/employees/{id}` | 퇴사 처리 (급여 내역 보존을 위해 실제 삭제하지 않음) |

직원 등록·수정 시 통상시급이 최저임금(2026년 10,320원)보다 낮으면 거부합니다.
월급제는 월 기본급 ÷ 월 소정근로시간으로 비교합니다.

## 실행 방법

```bash
# Backend (JDK 21 필요, 기본 프로필은 H2 메모리 DB)
cd backend
./gradlew bootRun

# Frontend
cd frontend
npm install
npm run dev
```
